Audiobook Creator - PATCHED FULL PACKAGE
=========================================
Source: https://github.com/img2vid/audiobookcreator
State:  Upstream + BOTH TTS fixes applied (2 commits):
        1. "Route TTS through established OS speech engines; honor engine selection"
        2. "Retire fake TTS engine packs; route every remaining entry through real OS engines"

What was fixed
--------------
- OS-level TTS now renders through established speech engines: Windows SAPI 5,
  macOS Apple Speech (say), Linux espeak-ng/espeak, plus optional Piper neural
  voices - for previews AND file exports (previously everything was silently
  re-rendered by a built-in robotic formant synthesizer).
- Engine selection is honored end-to-end: OS Classic vs Neural vs Piper vs
  OS Speech Engine all pick different real voices.
- The 7 fake/simulated catalog entries (AuraVoice Formant Core/Studio, VoxMecha,
  Storybook, WhisperKit Profiles, DeepContext Pro, EmotiveX) were removed; they
  were never real engines. Polyglot/Clarity are now honest selectors over your
  installed OS voices. Previews and voice-library auditions use the exact same
  render path as file exports. Fallbacks announce themselves with a reason.

How to run
----------
1. npm install
2. npm run os-tts        (the OS speech bridge - KEEP THIS RUNNING)
3. npm run dev           (then open http://localhost:3000)

Optional, for the most realistic voices: install Piper
(https://github.com/rhasspy/piper) and set PIPER_VOICES_DIR when starting
the bridge. Windows SAPI and macOS say need no installation at all.

Full documentation: docs/OS_TTS_BRIDGE.md (in this package).

Notes
-----
- out/ contains a pre-built static site (GitHub Pages ready); regenerate with
  npm run build. The bridge (npm run os-tts) is still required for file exports.
- public/ort/ contains local ONNX runtime assets used by the OCR/model features
  (they are normally fetched by npm run prepare:local-assets; included here so
  the package runs fully offline).
- node_modules is intentionally not included - run npm install.
